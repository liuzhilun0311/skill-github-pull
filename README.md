# GitHub 技能安装 (skill-github-pull)

根据明确提供的 GitHub 链接安装技能，并在已有版本内容不同时展示差异，由用户选择跳过、查看详情或备份后更新。

英文调用标识是 `$skill-github-pull`，界面显示为“GitHub 技能安装 (skill-github-pull)”。

## 安装与准备

将完整技能目录放入宿主支持的用户技能目录并刷新，不要遗漏 `scripts/compare_skill.py`。
需要可用的 GitHub 连接器、Git 或 HTTPS 下载能力；私有仓库需要宿主已有的访问权限。
本技能不自动安装下载工具，也不会要求在公开对话中输出令牌。

本地文件比较脚本需要 Python 3.9+，仅使用标准库，不需要安装被比较技能的运行依赖。

## 输入与调用

支持仓库根地址、`.git` 地址、指定分支或提交的技能子目录，以及指向 `SKILL.md` 的 GitHub 文件链接。
以下 `OWNER`、`REPO` 和目录名均为需要替换的示例：

```text
使用 $skill-github-pull 安装 https://github.com/OWNER/REPO 中的技能。
```

```text
使用 $skill-github-pull 安装以下两个链接：
https://github.com/OWNER/REPO/tree/main/skills/example-skill
https://github.com/OWNER/ANOTHER-REPO
```

```text
使用 $skill-github-pull 检查这个链接与我已安装版本的差异，
本次只查看，不安装也不覆盖。
```

没有链接时会请求补充，不从账号或历史仓库猜测目标。
一个仓库发现多个技能时，先列出候选供选择；链接精确指向一个技能时，不扩展到相邻技能。

## 安装与更新行为

| 情况 | 处理方式 |
| --- | --- |
| 所选技能尚未安装 | 安全获取完整文件并安装 |
| 已安装，完整内容相同 | 跳过，不重复安装 |
| 已安装，内容不同 | 展示新增、修改和删除文件，等待选择 |
| 同名但来源不同 | 展示来源冲突，要求明确选择 |
| 来源、权限或完整性不确定 | 说明原因，暂停该项，不覆盖 |

“安装这些链接”不等于授权覆盖已有技能。
备份更新前会重新检查内容是否变化；下载和安装固定到同一个提交，不在过程中悄悄切换版本。
没有历史基线时只能判断内容不同，不能断言远程版本更新。

## 输出与记录

结果按安装、更新、跳过、失败和等待选择汇总。
成功项会核对安装文件内容，并给出来源和必要的备份位置。

Codex 默认安装位置为 `$CODEX_HOME/skills`，未设置时为 `~/.codex/skills`。
记录和备份放在技能目录之外的 `$CODEX_HOME/skill-github-pull/`，未设置时使用 `~/.codex/skill-github-pull/`。
其中 `records/` 保存成功安装的来源和文件摘要，`backups/` 保存更新前的旧版本。
记录中的 `installed_at` 可能随更新变化，不应据此推断历史首次获取时间。

## 可选的本地比较

从本技能目录执行，路径需要替换为真实的暂存目录和安装目录：

```text
python scripts/compare_skill.py --staged "<完整暂存目录>" --installed "<安装目录>" --source "owner/repo:技能相对目录"
```

加 `--diff` 可以查看文本差异；存在历史记录时可通过 `--baseline` 指定记录文件。
脚本只读比较，输出 JSON，不自动安装或更新。

## 安全边界

不执行远程技能脚本、安装钩子或其中要求读取凭据的命令。
拒绝路径穿越、不安全链接及可能覆盖目标之外文件的归档条目。
安装不代表自动运行技能、安装其依赖或调用付费服务。
默认不扫描整个 GitHub 账号，也不创建、修改或推送仓库。

完整规则见 [SKILL.md](SKILL.md)。
